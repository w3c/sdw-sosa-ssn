System Capabilities Module

The System Capabilities Module imports SOSA and SSN and contains additional definitions associated with the capabilities, operating range, and survival range of systems.

The namespace for the system capabilities module is http://www.w3.org/ns/ssn/systems/
The suggested prefix for the system capabilities, operating ranges, and survival ranges terms is ssn-system

An RDF graph for this is available.

The SSN-System graph is available at https://www.w3.org/ns/ssn/systems/.

ssn-system:SystemObservation

IRI: http://www.w3.org/ns/ssn/systems/SystemObservation

an OWL Class

System Observation - Act of carrying out an (Observation) Procedure to estimate or calculate a value of a SystemProperty (accuracy, range, precision, etc.). The sosa:observedProperty (e.g., precision) qualifies the sosa:forProperty (e.g., temperature). For example, the precision (sosa:observedProperty) of the temperature (sosa:forProperty) may be 0.01 °C. Links to a sosa:FeatureOfInterest to detail what entity that property was associated with. Optionally links (with ssn-system:inCondition) to the prevailing conditions under which the estimation holds.

Sub class of sosa:Observation
Restrictions sosa:hasFeatureOfInterest ONLY sosa:System
sosa:observedProperty ONLY ssn-system:SystemProperty

ssn-system:OperatingRangeProperty

IRI: http://www.w3.org/ns/ssn/systems/OperatingRangeProperty

an OWL Class

Operating Range Property - An identifiable characteristic of a System that represents the conditions under which it is expected to operate normally. For example, the maximum temperature a System can withstand before being considered damaged.
Within the operating range, the System continues to operate as defined using SystemObservation of its SystemCapabilityProperty.

ssn-system:SurvivalRangeProperty

IRI: http://www.w3.org/ns/ssn/systems/SurvivalRangeProperty

an OWL Class

Survival Range Property - An identifiable characteristic of a System that represents the conditions it can be exposed to without damage. For example, the maximum temperature a System can withstand before being considered damaged.
If the survival range is violated, the System is 'damaged' and may cease to operate normally.
