SensorThings API Alignment

The OGC SensorThings API ([[STA]]) is a JSON API for the internet of things sensor data. As such, the alignment with the SSN Ontology cannot be axiomatized using OWL and RDFS. Nevertheless, alignment of STA may be understood using [[OMS]] as the bridge, as follows:

  • an alignment of SensorThings entities to OMS concepts is provided in Table 1 of [[[STA2]]]
  • the OMS Extension Module provides the SSN implementation of OMS
OGC SensorThings API entities and equivalent concepts in OMS with the mappings to SSN
STA Entity OMS Concept SSN Class
Thing Host sosa:Platform
Datastream ObservationCollection sosa:ObservationCollection
Sensor Observer sosa:Sensor
Observation Observation sosa:Observation
ObservedProperty Observed Property sosa:Property
Feature Feature sosa:FeatureOfInterest
