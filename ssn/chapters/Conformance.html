General conformance requirements

Data conforms to SSN if:

  • Access to data is organized around Actuations, Observations, and Samplings. These respectively represent executions of Actuating, Observing, and Sampling procedures, which are implemented by Actuators, Sensors, and Samplers, respectively.
  • The contents of all data fields are expressed using the appropriate RDF classes and properties from SSN. Where no such class or property exists, sub-classes or sub-properties specializing SSN in a domain-specific web ontology are employed.
  • Classes and properties from SSN must be used in a way consistent with the semantics declared in this Recommendation. Any subclasses or sub-properties of SSN terms that are defined in domain-specific ontologies must also be consistent with the SSN definitions.

SSN-compliant knowledge graphs MAY include additional non-SSN class instances, object and data properties, and additional RDF data.

Conformance with OGC Standards

OGC Standards are required to follow the OGC Modular Specification policy [[ModSpec]]. The key provisions of this policy are that:

  • Requirements states in a standard are organized into Requirements Classes and Conformance Classes
  • Each individual Requirement is a member of one and only one Requirements Class
  • Each individual conformance Test is a member of one and only one Conformance Class
  • Each Requirement, Requirements Class, Test, and Conformance Class shall be assigned a unique identifier and/or label (usually an IRI)
  • Dependencies are managed at the Requirements Class or Conformance Class level
  • No circular dependencies are permitted
  • Conformance to the standard is assessed at the Conformance Class level
  • A requirements target type is specified

The SSN Ontology Modularization () is consistent with this policy.

Ten core modules are defined, each module packaged into an RDF file that implements the module. Each module corresponds to an OGC Requirements Class. Dependencies between modules are recorded in the RDF through the owl:imports property. The definition of each term in the SSN Ontology corresponds to a single Requirement.
