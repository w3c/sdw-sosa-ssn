OGC API – Connected Systems Alignment

OGC API – Connected Systems (CSAPI) is a multipart OGC Web API standard for accessing and managing connected systems and their associated resources. Part 1 [[CSAPI-1]] defines feature resources and property definitions; Part 2 [[CSAPI-2]] defines dynamic-data resources, including datastreams, observations, control streams, and commands. CSAPI uses SOSA/SSN concepts as a basis for its resource model and expresses corresponding information through resource representations, attributes, and associations.

The tables below describe selected conceptual correspondences between CSAPI 1.0 and the classes and properties defined in this edition of SSN, rather than formal OWL equivalence axioms.

Observation sosa:Observation Some information may be supplied by the parent DataStream; CSAPI permits multiple observed properties in one resource. Part 2, 9.7
ControlStream sosa:ActuationCollection Commands share the same receiving System, controlled properties, and parameter schema. Part 2, 10.2
Command sosa:Actuation Generalizes Actuation; a command may be rejected without execution. Part 2, 10.7

Each attribute or association below is interpreted in the context of its source resource. Association correspondences relate that resource to the associated entities; for example, DataStream observations relates a datastream to its member observations. Association names also appear in CSAPI link relations, such as ogc-rel:subsystems.
