OGC Modular Specification identifiers

OGC Standards are required to following the OGC Modular Specification policy [[ModSpec]]. The key provisions of this policy are that:

  • the standard is organized into Requirements Classes and Conformance Classes
  • each individual Requirement is a member of one and only one Requirements Class
  • each individual conformance Test is a member of one and only one Conformance Class
  • each Requirement, Requirements Class, Test, and Conformance Class is denoted by an IRI
  • dependencies are managed at the Requirements/Conformance Class level
  • no circular dependencies are allowed
  • Conformance to the standard is assessed at the Conformance Class level
  • the conformance target type is specified

The SSN Ontology Modularization () is consistent with this policy.

Ten core modules are defined, each module packaged into an RDF file that implements the module. Each module corresponds to a Requirements Class, and is denoted by the Ontology IRI. Dependencies between modules are indicated by the use of the owl:imports property.

The definition of each term in the SSN Ontology corresponds to a single Requirement. Membership in a module is indicated by the rdfs:isDefinedBy property.
